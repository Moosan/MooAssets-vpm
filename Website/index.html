MooAssets · VPM Listing

VCC への追加手順

  1. VCC を開き Settings へ
  2. Packages タブ → Add Repository
  3. Listing URL を貼り付け → Add
  4. 内容を確認して I Understand
  5. プロジェクトの Manage Project で MooAssets にチェック
