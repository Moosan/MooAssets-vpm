アップデート・移行ガイド

過去に UnityPackage（Assets/MooAssets）で入れた人向け。VPM v1.1.0 以降は VCC 経由が正規ルートです。当面 BOOTH 等での配布は行わず、友人間ではこのページの URL を共有してください。

UnityPackage → VPM（初めて VPM に切り替える）

  1. プロジェクトをバックアップ（Git コミットまたは zip 退避）
  2. 旧 Assets/MooAssets フォルダを削除（VPM と二重に置くと Missing / 重複コンパイルの原因）
  3. 自分のワールド用スクリプトで旧 API を使っている場合は先に修正（下記「API 変更」参照）
  4. 上記「VCC に登録」の Listing URL を VCC に追加
  5. Manage Project で MooAssets をインストール → Unity 再起動
  6. UdonSharp → Compile All UdonSharp Programs を実行
  7. シーン・Prefab を開き、Missing Script・Console エラーがないか確認

すでに VPM 入り済みのプロジェクトを更新する

  1. VCC で Listing を Refresh（作者が Release zip を差し替えた場合は Listing 再ビルド後）
  2. Manage Project で MooAssets を Remove → 同バージョンまたは新バージョンを再 Install（または VCC の更新 UI で上げる）
  3. Unity 再起動 → UdonSharp 全コンパイル
  4. Packages/com.moulabo.mooassets は直接編集しない（上書きされる）。カスタムは Assets/ 側に置く

壊れにくくするコツ

  • Prefab / シーン参照: パッケージ内 Prefab を Hierarchy に置いた参照は GUID 維持のため通常はそのまま。Missing が出たら同バージョンの Prefab を入れ直す
  • 依存パッケージ: FukuroUdon・VRCLightVolumes は VCC が自動解決。手動で古い版だけ残さない
  • カスタム Udon: パッケージ内スクリプトをコピーして改変している場合、VPM 更新で上書きされないが、正本 API 変更時は自分のコピーも追従が必要

主な API 変更（1.1.0 / VPM 移行時）

旧（UnityPackage 時代）新（VPM）
MooAssets.Util.InAreaPlayer
BaseInAreaEventListener / InAreaPlayer		MooAssets.Util.AreaPlayer
AreaPlayerNotify + AreaPlayerUpdate / LocalPlayerIn 等のカスタムイベント
Assets/MooAssets/ 配下Packages/com.moulabo.mooassets/

SoundSpaceSystem・AreaPlayerCountEventEntry 等、正本側の利用例はパッケージ内 Runtime/Util/ を参照。独自ギミック（例: VoiceObserveArea）は AreaPlayerNotify を Inspector で notifyReceivers に登録する形に書き換える。
